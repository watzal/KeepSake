# Keepsake API

The FastAPI backend for Keepsake. This folder is also what gets pushed to the Hugging Face Space
that hosts it; the block above is the Space's configuration.

Settings come from environment variables (see `.env.example`). On the Space they are set under
Settings → Variables and secrets.
